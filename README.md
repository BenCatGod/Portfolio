# Benya Pengkhuean — Portfolio Website

A modern, dark-themed personal portfolio built with **Vite + React + Tailwind CSS**.

## Getting started

```bash
npm install
npm run dev       # http://localhost:5173
```

```bash
npm run build      # production build → dist/
npm run preview    # preview the production build locally
```

## Project structure

```
portfolio-website/
├─ .github/workflows/build.yml   # CI: install + build on push
├─ public/                       # static assets served as-is (favicon, etc.)
├─ src/
│  ├─ assets/                    # images/icons imported by components
│  ├─ components/                # Topbar, NavDock, Sidebar, Pill, ProjectCard, ...
│  ├─ data/                      # experience.js, studies.js, skills.js, projects.js
│  ├─ hooks/                     # useClock, useTheme, useScrollSpy
│  ├─ pages/                     # About.jsx (/), Work.jsx (/work)
│  ├─ utils/                     # small helpers (cn.js)
│  ├─ App.jsx                    # routes + shared layout chrome
│  ├─ index.css                  # design tokens + component styles (Tailwind layered in)
│  └─ main.jsx                   # React root, BrowserRouter
├─ index.html
├─ package.json
├─ postcss.config.js
├─ tailwind.config.js
└─ vite.config.js
```

`node_modules/` and `dist/` are generated by `npm install` / `npm run build` and are
git-ignored — they show up locally but aren't part of the source tree.

## Editing content

All page copy lives in `src/data/*.js` — edit those files to update work experience,
studies, skills, or project cards without touching any component markup.

## Design notes

- Palette: deep navy background with a warm amber accent (`--accent`), defined as CSS
  custom properties in `src/index.css` and mapped into Tailwind via `tailwind.config.js`.
- Type: Space Grotesk (display), Inter (body), JetBrains Mono (timestamps, tags, labels).
- The nav dock (`src/components/NavDock.jsx`) has a real sliding indicator that animates
  to the active tab, measured with `getBoundingClientRect`.
- Theme toggle persists to `localStorage` via `useTheme`.
- Sidebar section links use `useScrollSpy` (IntersectionObserver) to highlight the
  section currently in view.
